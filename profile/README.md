# Shopinator

We build Shopify apps for checkout and delivery. Every app starts with a real problem in a real store, and we turn it
into an app with security, data privacy and direct support built in.

## Apps

### Address Validator

Blocks checkout when a delivery address has no house number or postal code, even on Shop Pay, PayPal, Apple Pay and
Google Pay. Rules are set per country, and buyer messages come in 33 languages. For Shopify merchants whose parcels
come back because an address was incomplete.

[Address Validator on the Shopify App Store](https://apps.shopify.com/checkout-address-validator-1) ·
[Docs](https://shopinator.io/docs/address-validator)

### Delivery Date

Coming soon.

Shows shoppers an estimated delivery date on the storefront, in checkout and after purchase. For Shopify merchants
who want shoppers to see when an order will arrive.
